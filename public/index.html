Set up the Tenderkart connection on this computer

Use normal Chrome or Edge. Install the connector once; then Sync latest uses the Tenderkart tab where you are signed in. Login tokens remain inside Tenderkart.

  1. Download the connector and extract it, or use the connector folder in this project.
  2. Open chrome://extensions (or edge://extensions), enable Developer mode, select Load unpacked, and choose that connector folder.
  3. Reload this portal, click Sync latest and sign into Tenderkart in the tab that opens. Keep that tab and this server running.
